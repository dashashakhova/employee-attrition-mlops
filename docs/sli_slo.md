# SLI и SLO для Employee Attrition Prediction Platform

## 1. Технический уровень

### API Availability

SLI:
Доля успешных запросов к FastAPI сервису.

SLO:
Не менее 99% успешных запросов за месяц.

---

### API Latency

SLI:
Среднее время ответа API.

SLO:
Среднее время ответа не более 2 секунд.

---

### Error Rate

SLI:
Доля запросов, завершившихся ошибкой.

SLO:
Не более 1% ошибок.

---

## 2. Уровень модели

### ROC-AUC

SLI:
ROC-AUC модели на контрольной выборке.

SLO:
ROC-AUC не ниже 0.75.

---

### Precision

SLI:
Precision модели.

SLO:
Не ниже 0.70.

---

### Recall

SLI:
Recall модели.

SLO:
Не ниже 0.30.

---

### Data Drift

SLI:
Изменение распределения признаков относительно обучающей выборки

SLO:
Не более 10% отклонения по ключевым признакам.

При превышении порога инициируется переобучение модели.

---

## 3. Бизнес-уровень

### Employee Attrition Reduction

SLI:
Количество сотрудников, для которых система заранее выявила высокий риск увольнения.

SLO:
Не менее 70% увольнений должны быть обнаружены системой заранее.

---

### HR Analytics Coverage

SLI:
Доля сотрудников, для которых рассчитывается риск увольнения.

SLO:
Не менее 95% сотрудников компании должны проходить оценку системой.
