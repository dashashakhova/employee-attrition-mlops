# ADR: Выбор архитектуры на основе анализа latency

## Status

Accepted

## Context

В рамках Metrics Driven Development проведено сравнение двух архитектурных реализаций системы по метрике latency.

Для анализа использованы два набора наблюдений:

* Existing System (среднее время отклика около 3.5 секунд);
* Improved System (среднее время отклика около 2.0 секунд).

Цель анализа — определить, приводит ли новая архитектура к статистически значимому снижению времени ответа.

## Hypotheses

Нулевая гипотеза (H0):

Среднее время отклика новой архитектуры не отличается от времени отклика существующей системы.

Альтернативная гипотеза (H1):

Среднее время отклика новой архитектуры меньше времени отклика существующей системы.

## Statistical Test

Используется двухвыборочный t-test для независимых выборок.

Уровень значимости:

α = 0.05

Результат:

p-value < 0.001

Полученное значение меньше уровня значимости.

Следовательно, нулевая гипотеза отвергается.

## Decision

На основании статистического анализа принимается решение использовать улучшенную архитектуру системы.

Архитектурное решение обосновано статистически значимым снижением latency по сравнению с существующей системой.

## Consequences

Положительные последствия:

* снижение времени ответа сервиса;
* улучшение пользовательского опыта;
* выполнение SLO по latency.

Отрицательные последствия:

* необходимость поддержки новой версии архитектуры.
